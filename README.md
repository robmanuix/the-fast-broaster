# The Fast Broaster

Sitio web estático (HTML5, CSS3 y JavaScript vanilla, sin dependencias) para The Fast Broaster.

## Secciones

- **Header** fijo con logo circular central y menú responsive.
- **Hero** con carrusel de fondo (3 imágenes), overlay oscuro, copy propio por slide con entrada escalonada, autoplay, barra de progreso, flechas, puntos y swipe.
- **Nosotros** con mosaico de 3 fotos y fondo texturizado.
- **Combos**: carrusel horizontal de 4 combos con ilustraciones flotantes en parallax.
- **Delivery**: franja de imagen + panel rojo.
- **Footer** fijo al fondo (efecto cortina) con direcciones, contacto y redes.

## Estructura

```
index.html
assets/
  css/styles.css
  js/main.js
  img/
```

Tipografías: Teko (títulos y CTAs) y Overpass (texto), servidas desde Google Fonts.
